A selection of personal and open-source projects. More on
[GitHub](https://github.com/thompsy).

## go-linux-worker
A Go service that executes arbitrary Linux commands on behalf of clients, isolating each job
with Linux **namespaces** and constraining resources with **cgroups** — built to understand how
containers work under the hood. gRPC client/server, Dockerised.
[Source](https://github.com/thompsy/go-linux-worker)

## mini-llm-platform
A small, self-hosted LLM platform built to sharpen Python and build hands-on LLM understanding:
a typed FastAPI inference API over Ollama, RAG with vector retrieval and citations, request
tracing, and an evaluation harness.
[Source](https://github.com/thompsy/mini-llm-platform)

## eBPF Summit 2021 CTF
A series of eBPF Capture-the-Flag challenges I participated in as part of the eBPF Summit 2021.
[Source](https://github.com/thompsy/ebpf-summit-2021-ctf)

## planck-ez-firmware
Cloud-built QMK firmware for the Planck EZ Glow — a tweaked Miryoku layout (Colemak-DH,
home-row mods), compiled in GitHub Actions with one-step flashing.
[Source](https://github.com/thompsy/planck-ez-firmware)

## jLTE-Simulator (PhD)
The physical-layer LTE network simulator built during my PhD on self-organisation in LTE
networks. See the [thesis](/projects/jLTE-Simulator/) for the full write-up.
[Source](https://github.com/thompsy/jLTE-Simulator)
